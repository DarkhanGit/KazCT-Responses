**Registration update 1 (31 October 2026) — selection of the open-weight LLM.** The pre-registered smoke test (60 synthetic responses, 30 per language; criteria: loads in 4-bit on an 8 GB GPU, ≥ 95% format-valid single-digit outputs, throughput) was run on 31 October 2026 with Transformers 5.21.0 and bitsandbytes 0.50.2. Results: issai/Qwen3.5-9B-Kazakh (revision 92c4210d5f0f) — loaded (7.6 GB), 100% format-valid in both languages, 15.4 s per response; issai/LLama-3.1-KazLLM-1.0-8B (015343c542fa) — loaded (5.7 GB), 88.3% (Russian 100%, Kazakh 76.7%), 0.61 s; inception42/Llama-3.1-Sherkala-8B-Chat (ab873dfe8b5c) — loaded (6.0 GB), 91.7% (100% / 83.3%), 0.41 s; Sherkala's tokenizer has no chat template, so the standard Llama-3 template was supplied. By the pre-registered rule, **Qwen3.5-9B-Kazakh is the LLM used in all pre-registered LLM conditions**. In addition, and announced here before any real response has been scored by any LLM, KazLLM-1.0-8B will be run as a **supplementary, non-pre-registered row** with the same prompts and a lenient parser (first digit 0–4 in the output; share of non-conforming outputs reported); it is excluded from all hypothesis tests and Holm-corrected comparisons and is reported for the benefit of readers interested in the national model. Smoke-test files (smoke_results.csv, smoke_outputs.csv) are added to the project files. No real response has been scored by any rater-independent model as of this update.
